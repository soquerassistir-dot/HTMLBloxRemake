HTMLBlox Studio

Unified Editor — 3D parts, scripts, physics, and player avatar in one place.

Test mode (F5): saves a snapshot of the workspace, then runs the game with physics and scripts. When you press Stop, everything is reverted to how it was before Play.

Scripts only run on F5. They will not run in editor mode. Scripts have full access to variables, loops, conditions, functions, and a Roblox-like API.

Controls: WASD to move camera, RMB to orbit, Wheel to zoom. Select a part, then use the gizmo to move/rotate/scale. Unanchored parts fall under gravity in the editor too.

Blok Scripting Manual

Introduction

Blok is the scripting language of HTMLBlox Studio. Scripts run when you press F5 (Play).

Basics

print(value)

Prints a message to the Output panel.

print("Hello, world!")
print(42)
print(2 + 3)

Variables

local x = 5
local name = "Player"
local isFast = true
x = x + 10

Loops

-- Numeric for
for i = 1, 10 do
  print("Count: " .. i)
end

-- While loop
local n = 0
while n < 5 do
  print(n)
  n = n + 1
end

Conditions

local score = 100
if score >= 90 then
  print("A")
elseif score >= 70 then
  print("B")
else
  print("C")
end

Functions

local function add(a, b)
  return a + b
end

print(add(3, 4))

Workspace API

workspace:CreatePart(kind, options)

Creates a new part. kind is "Part", "Wedge", "Sphere", or "Cylinder".

local p = workspace:CreatePart("Part", {
  Name = "MyBlock",
  Position = Vector3.new(0, 5, 0),
  Size = Vector3.new(4, 1, 4),
  Color = "#ff0000",
  Anchored = true
})

workspace:FindPart(name)

Finds a part by name anywhere in the workspace.

local base = workspace:FindPart("Baseplate")
if base then
  base.Color = "#00ff00"
end

workspace:FindFirstChild(name)

Finds a direct child by name.

workspace:WaitForChild(name, timeout)

Waits until a child exists. Yields the script.

workspace:GetChildren() / GetDescendants()

Returns a table of all children (or descendants).

Part Properties

Every part wrapper exposes:

  • .Name — string
  • .Position — Vector3 (get/set)
  • .Size — Vector3 (get/set)
  • .Rotation — Vector3 in degrees
  • .Color — string hex or number
  • .Transparency — 0..1
  • .Anchored — boolean
  • .CanCollide — boolean

Methods: Spin(x,y,z), StopSpin(), Tween(prop, target, time), Destroy(), Clone()

Vectors

local v = Vector3.new(1, 2, 3)
print(v.x, v.y, v.z)
print(v.Magnitude)
print(v + Vector3.new(1, 0, 0))

Utility functions

  • wait(seconds) / task.wait(seconds)
  • spawn(fn) / task.spawn(fn)
  • task.delay(seconds, fn)
  • math.random(a, b), math.floor, math.sin...
  • string.format(fmt, ...)
  • table.insert, table.remove, table.sort

Example: Build a Stairway

for i = 1, 10 do
  local y = i * 1
  local z = i * 2
  workspace:CreatePart("Part", {
    Name = "Step" .. i,
    Position = Vector3.new(0, y, z),
    Size = Vector3.new(6, 1, 2),
    Color = "#a3a2a5",
    Anchored = true
  })
end

print("Stairs done")

Example: Spinning Part

local p = workspace:CreatePart("Part", {
  Name = "Spinner",
  Position = Vector3.new(0, 5, 0),
  Size = Vector3.new(2, 2, 2),
  Color = "#ffaa00",
  Anchored = true
})

p:Spin(0, 90, 0) -- degrees per second
wait(5)
p:StopSpin()
