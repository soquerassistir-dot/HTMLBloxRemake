Version 0.5.0 (alpha)
This version is still under development.
The Baseplate is now a regular Part — you can move it, resize it, recolor it or delete it. If you delete it, the engine will NOT regenerate it (the map will have no floor).
Quick tips:
• WASD — move camera · RMB — orbit · Wheel — zoom
• W/E/R/Q — Translate / Rotate / Scale / Select
• Ctrl+D — Duplicate · Del — Delete
• F5 — Play. All scripts inside Workspace run automatically.
• Click Publish to set name, description, thumbnail (upload from PC) and visibility.
Blok Language Manual

Introduction

Blok is the scripting language of HTMLBlox Studio. Scripts run automatically when you press Play (or F5).

Commands

print( value )

Prints a message to the Output panel.

print("Hello, world!")
print(42)

workspace:CreatePart( x, y, z, sx, sy, sz, color )

Creates a new Part in the workspace.

workspace:CreatePart(0, 5, 0, 4, 4, 4, 0xff0000)
workspace:CreatePart(10, 2, 0, 8, 1, 8, 0x00ff00)

Examples

Stairway

print("Building stairs...")

workspace:CreatePart(0, 1, 0, 6, 1, 6, 0xa3a2a5)
workspace:CreatePart(0, 2, 6, 6, 1, 6, 0xa3a2a5)
workspace:CreatePart(0, 3, 12, 6, 1, 6, 0xa3a2a5)
workspace:CreatePart(0, 4, 18, 6, 1, 6, 0xa3a2a5)

print("Done!")

Limitations

  • No variables, loops, conditionals, or functions yet.
  • Events and networking are not implemented.
  • Use -- for comments.
